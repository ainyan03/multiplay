# MULTIPLAY

ブラウザだけで自由に参加・退出できる、サーバーレスP2Pオンライン・ミニゲーム集のプロトタイプです。

## 収録ゲーム

- **GEM SPRINT** — フィールド上の宝石を集めるスコアアタック
- **CROWN CHASE** — 王冠を奪い合い、保持時間を競うおにごっこ
- **PULSE PUSH** — 衝撃波で相手を場外へ押し出すサバイバル
- **LOBBY PLAZA** — キャラクターで歩き、マップ上の入口からゲームを選べる常設広場

いずれもゲーム中の途中参加・途中退出が可能です。プレイヤーの位置とゲームイベントは約15Hzで同期します。ロビーと全ゲームを横断する常設チャットがあり、発言はログとキャラクター頭上の吹き出しに表示されます。

スマホでは全ゲーム共通の仮想方向パッド、決定／アクションボタン、チャットボタンを表示します。横画面ではチャットを中央下、コントローラを左右に配置し、縦画面ではチャットをコントローラの上に配置します。チャット入力中はスクリーンキーボードを優先してコントローラを隠します。チャットは最小化・通常・拡大の3段階で切り替えられ、自分と他プレイヤーの発言は色分けされます。

## 仕組み

```text
静的Webサイト
    └─ 公開Nostrリレー: 部屋にいるブラウザ同士の発見とWebRTCシグナリング
          └─ WebRTC DataChannel: 位置・得点・ゲームイベントをP2Pで直接送受信
```

通信には Trystero の Nostr 戦略を利用しています。ゲームデータを中継する専用サーバーはありません。NATの組み合わせによって直接接続できない利用者がいる点は、STUNのみのP2P構成上の制約です。本格運用時はTURNを追加してください。

## 開発

```bash
npm install
npm run dev
npm test
```

`http://localhost:3000` を複数タブまたは複数端末で開き、同じゲームに参加すると接続できます。公開Nostrリレーを利用するためインターネット接続が必要です。

GitHub の `ainyan03/multiplay` リポジトリへ `main` ブランチを送ると、GitHub Actions がテストと静的ビルドを実行し、GitHub Pagesへ自動公開します。

公開URL: `https://ainyan03.github.io/multiplay/`

初回のみGitHubリポジトリの **Settings → Pages → Source** を **GitHub Actions** に設定してください。Giteaの `ainyan/multiplay` は開発元、GitHubは公開用ミラーとして利用できます。

## ゲーム追加の方針

ゲーム選択情報は `app/arcade.tsx` の `GAMES`、ゲームルールは同ファイルの更新ループと描画処理にまとまっています。次の段階ではゲームごとに `GameDefinition`（初期化・更新・描画・イベント処理）へ分離し、共通のルーム接続・プレイヤー同期を再利用する構成に拡張できます。

ファミコン期のゲームからは「1画面で状況が読める」「操作が方向キーと1ボタンで完結する」「短時間で勝敗がつく」という設計原則だけを参照し、固有名称・キャラクター・グラフィック・ステージは使用しません。
